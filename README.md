# Billiards Controller (ESP32 / ESP-IDF)

Прошивка системы управления для бильярдного автомата на базе микроконтроллера ESP32.

## Описание
Проект предназначен для обработки сигналов монетоприёмника, управления дисплеем, взаимодействия с системой QR-оплаты и учета игрового времени.

## Особенности
- **Фреймворк:** ESP-IDF
- **Фильтрация сигналов:** Аппаратная + программный антидребезг (60 мс)
- **Модульная структура:** Раздельная логика обработчиков периферии
